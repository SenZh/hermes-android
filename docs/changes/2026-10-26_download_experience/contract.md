# 产出契约 (Contract)

## 一、 主路径完成标准 (Happy Path Criteria)
1. **前置选目录验证**：点击【下载到本地】或右上角下载时，首先且仅调起 `Directory.pickDirectoryAsync()`；用户未选目录或点击系统返回取消时，Promise 返回空，网络请求数为 0。
2. **进度速度实时呈现**：在流式下载运行过程中，界面实时刷新文本与进度条（包含百分比 `progress %`、瞬时速度 `X.X MB/s`、已写入 `A MB / B MB`），更新频率由 150ms 节流阀管控。
3. **完成态与双按钮呈现**：下载流式落盘成功后，卡片立即呈现【📄 打开文件】与【📁 打开所在目录】，并且右上角图标联动为已完成状态。
4. **重进持久化命中**：退出当前会话/重新进入该文件查看页，组件挂载即核验已保存的落盘记录；在目标文件存在且有效时，直接以完成态渲染。

## 二、 异常与边界完成标准 (Edge Case Criteria)
1. **同名冲突覆盖 (Overwrite)**：目标文件夹中已存在同名文件，用户选择【覆盖】，系统先删除同名目标，落盘新文件，绝不生成 `(1)` 副本。
2. **同名冲突重命名 (Auto-Rename)**：用户选择【自动重命名】，系统自动将新文件保存为 `<name> (1).<ext>`（若已有 (1) 则递增至 (2)）。
3. **外部删除失效容错**：若用户在系统文件管理器中手动删除了已下载的文件，App 重新进入该页面时，`exists` 校验失败并安全回退至未下载态，绝不发生白屏或 NullPointerException。
4. **网络中断恢复**：网络下载中断或非 200 时，状态机安全转移至 `error` 并 Toast 报错，临时缓存自动清除，界面允许重试。

## 三、 相邻影响与安全红线 (Safety & Blast Radius)
1. **零内存 Base64 铁律**：严禁调用任何 `.base64()` 或 `readAsStringAsync()`，大文件全链路流式传输，堆内存膨胀为 0。
2. **多语言 100% 覆盖**：新增文案全部在 `src/i18n/zh.ts` 中完成中文映射，`check-i18n.mjs` 0 报错。
